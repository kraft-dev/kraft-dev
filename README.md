### Чем это отличается от «просто бота»

- **Платежи, которые не теряются.** Вебхуки с проверкой подписи, идемпотентная обработка, автопродление подписки.
- **Инфраструктура, которая не падает ночью.** Docker, PostgreSQL, health-checks, автоперезапуск, регулярные бэкапы.
- **Уведомления с гарантией единственной доставки.** Состояние в базе, а не в памяти процесса — перезапуск бота не шлёт клиентам дубли.
- **Мини-приложения внутри Telegram.** С пошаговой установкой под iOS, Android, Windows и macOS.
